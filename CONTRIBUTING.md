# Contributing to Text2SQL Agent

Thank you for your interest in contributing!

This project follows a fork-based contribution model.

## Contribution Guidelines

1. Direct pushes to protected branches are not permitted.
2. All external contributions must originate from a personal fork.
3. Create a feature branch in your fork.
4. Submit a Pull Request against the official repository.
5. All PRs are subject to maintainer review and approval.
6. Automated tests and security checks must pass before merging.
7. Do not submit secrets, API keys, credentials, or sensitive data.
8. Follow the project's coding standards and security guidelines.

## Contribution Workflow

- Fork the repository.
- Clone your fork.
- Create a feature branch.
- Implement your changes and tests.
- Push changes to your fork.
- Open a Pull Request against the official repository.

The project maintainer reserves the right to review, request changes, approve, or reject contributions.

Thank you for helping improve the project!
